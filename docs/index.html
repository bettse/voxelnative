VoxelNative

I wanted to actually play Luanti on the Vision Pro, not stream a desktop into a floating window. So I wrote a client that renders the world itself, per-eye, in the headset.

What it is

A new Luanti network client written in Swift and Metal. It isn't a port of the engine; it talks the same wire protocol.

It speaks the Luanti UDP protocol directly: SRP login, zstd map-block streaming, node and item definitions, media download, entities, formspecs, HUD. An unmodified server sees it as just another client and hands over the whole game. The world is rendered per-eye with Compositor Services, meshed live as blocks stream in, and you walk around, dig, place, and open inventories with the PSVR2 Sense controllers (or a Bluetooth keyboard, with gaze to aim and a pinch to click).

It connects to any Luanti server. I build and test it against VoxeLibre (a Minecraft-like game for Luanti), so that's where the polish is, but the protocol layer doesn't care which game you run.

What works right now

  • The world streams in and is meshed live: cubes, nodeboxes, plants, meshes (chests, beds), rails, liquids and glass, with a day/night sky and fog.
  • Per-eye rendering through Compositor Services, with reprojection.
  • Digging, placing and crafting, with tool capabilities and wear. Chests, furnaces, anvils and other stations open as panels you point at.
  • PSVR2 Sense controllers for moving, turning and interacting. A Bluetooth keyboard with gaze and pinch also works.
  • Mobs, dropped items, projectiles, XP orbs and nametags, with animation and bone attachments.
  • Positional audio (HRTF, matching Luanti's OpenAL setup), particles, weather, damage feedback, armor, status effects and the experience bar.

Rough edges

It's a hobby project and still in progress. Things I know about:

  • Some deep-underground nodes still fall back to a placeholder look I haven't chased down.
  • No creative pick-block gesture yet; the VR control scheme is still being figured out.
  • Lots of the UX polish assumes VoxeLibre. Other Luanti games will connect and render, but may look rougher.

Try the beta

The easiest way in is the TestFlight public beta: open the link on your Vision Pro and install through the TestFlight app. You'll need PlayStation VR2 Sense controllers or a Bluetooth keyboard, and a Luanti server to join; the app doesn't host worlds itself. Feedback goes through TestFlight's own feedback button. Every button and key is on the controls page.

Build it yourself

You'll need Xcode and a Luanti server to point it at (a local dev server is fine). Set your own Apple Developer team for a device build.

git clone https://github.com/bettse/voxelnative
cd voxelnative/native

xcodegen                 # generate the Xcode project
open VoxelNative.xcodeproj   # run on Apple Vision Pro or the simulator

Set DEVELOPMENT_TEAM in native/project.yml before running on a device, and enter your server in the launcher.
