VoxelNative

A native Luanti client for Apple Vision Pro. Play Luanti / Minetest voxel games in full stereo immersion — no PC streaming, no server mods, just the whole game rendered live in the headset.

View on GitHub How to build

Built and tested against VoxeLibre, the Minecraft-style flagship game — but the protocol layer is game-agnostic.

What it is

A from-scratch Swift + Metal reimplementation of the Luanti network client.

VoxelNative speaks the Luanti UDP protocol directly — SRP login, zstd map-block streaming, node and item definitions, media download, entities, formspecs, HUD. An unmodified Luanti server sees it as just another client and hands over the entire game. The world is rendered in true stereo with Compositor Services, meshed live as blocks stream in, and you walk around, dig, place, and open inventories with the PSVR2 Sense controllers (or a Bluetooth keyboard and mouse).

Features

A real client, not a viewer.

🌍 Live world streaming

Real map blocks stream from the server and mesh on the fly, with all the Luanti drawtypes — nodeboxes, plants, meshes, rails, liquids, glass.

👓 True stereo immersion

Rendered per-eye with Metal + Compositor Services and reprojection, not a flat window floating in space.

🎮 PSVR2 Sense controllers

Locomotion, look, dig, place, and a spatial inventory / formspec UI you point at and tap.

⛏️ Dig, place, craft

Full interaction: tool caps and wear, crafting, chests, furnaces, anvils, and other station formspecs.

🔊 Positional audio

Server sounds play as real 3D sources with HRTF and true pitch, matching Luanti's OpenAL model.

🧩 Protocol-complete

Entities, particles, weather, day/night sky, damage, XP, armor, status effects — the wire protocol is broadly covered.

Build it yourself

Xcode + a Luanti server. You'll need your own Apple Developer team for device signing.

git clone https://github.com/bettse/voxelnative
cd voxelnative/native

# generate the Xcode project (uses XcodeGen)
xcodegen

# open and run on an Apple Vision Pro (or the simulator)
open VoxelNative.xcodeproj

Point it at any reachable Luanti server in the launcher (a local dev server works great). Set your own DEVELOPMENT_TEAM in native/project.yml before a device build.
